01 / INTERFACE

Launcher interface

ArmaLauncher brings the server browser, Workshop and installed mods into one desktop app. Keep a preset for each server or group so you can check your mod list before joining a session.

02 / PRESETS

Launcher features

01

Add the preset

Open a JSON file or paste a list from game.mods.

02

Check the mods

The launcher flags missing mods and version differences before launch.

03

Launch Arma Reforger

Only mods from the selected preset are enabled for this launch.

03 / CONTROL

Works with large libraries.

The scan reads mod metadata without unpacking archives, so checking hundreds of installed mods stays quick.

Saved presets

Keep separate mod lists for different servers and groups.

Dependencies

Add known dependencies together with the selected mods.

Path detection

Steam, Workshop, and profile folders are found automatically.

Repair tools

Reset launcher data and scan the library again when needed.
